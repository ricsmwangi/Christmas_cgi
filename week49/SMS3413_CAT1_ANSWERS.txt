2) First-order Stochastic Dominance (FSD) — Statement and proof sketch
Statement:
Random variable X first-order stochastically dominates Y (written X ⪰_FSD Y) if and only if
F_X(t) ≤ F_Y(t) for all t, with strict inequality on a set of positive measure for strict dominance.
Equivalently, for every increasing utility u, E[u(X)] ≥ E[u(Y)].

Proof sketch (⇒ direction):
If F_X(t) ≤ F_Y(t) ∀t, then X yields higher quantiles for all probabilities. For any increasing u,
by integration by parts or quantile coupling, E[u(X)] ≥ E[u(Y)].

Proof sketch (⇐ direction):
If E[u(X)] ≥ E[u(Y)] for all increasing u, choose indicator utilities u_z(x) = 1{x ≥ z} (approximated),
then E[u_z(X)] = P(X ≥ z) ≥ P(Y ≥ z) ⇒ 1 − F_X(z) ≥ 1 − F_Y(z) ⇒ F_X(z) ≤ F_Y(z) for all z.
Thus, FSD holds.

3) Long call vs forward (K=950, forward price=950)
- Long forward at price 950: Payoff at maturity = S_T − 950; zero cost today (ignoring margin); linear exposure.
- Long call with strike 950: Payoff = max(S_T − 950, 0); costs premium today; non-linear exposure with downside limited to premium.
Key differences:
- Optionality: Call provides right, not obligation; forward is obligation.
- Upfront cash: Call requires premium; forward typically no premium.
- Risk: Call caps downside at premium; forward has symmetric linear P/L.
- When S_T ≤ 950: Forward loses (950 − S_T); call expires worthless (loss = premium only).

6) Greeks — definitions and what they measure
- Delta (Δ): ∂V/∂S. Sensitivity of option value to small changes in underlying price; approx number of shares to delta-hedge.
- Gamma (Γ): ∂^2V/∂S^2. Curvature of value w.r.t. underlying; risk of delta changing; higher for near-the-money options.
- Theta (Θ): ∂V/∂t. Time decay; change in value as time passes (typically negative for long options).
- Vega (often denoted ν or κ/kappa in some texts): ∂V/∂σ. Sensitivity to volatility; long options have positive vega.
- Rho (ρ): ∂V/∂r. Sensitivity to interest rate; calls typically positive rho, puts negative.
Brief meanings:
- Δ: price sensitivity; hedge ratio.
- Γ: nonlinearity; how fast Δ changes.
- Θ: passage of time effect.
- Vega/κ: volatility exposure.
- ρ: interest-rate exposure.
